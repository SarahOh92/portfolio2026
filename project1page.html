헵시바F&B
Overview
헵시바F&B는 인공적인 맛보다 자연 그대로의 풍미, 일상 속에서 부담 없이 즐길 수 있는 건강 간식 생산하고, ‘정직함·깨끗함·건강함’을 핵심 가치로 내세우는 브랜드입니다.
리뉴얼 프로젝트는 기존 사이트가 지닌 브랜드 가치와 제품 철학을 더 명확하게 전달하고,컬러·일러스트·레이아웃 전반을 따뜻하고 친근한 방향으로 디자인 및 구축하였습니다.
  • 프로젝트 목적
    홈페이지 리뉴얼
  • 작업 기간
    2023. 12. - 2024. 04.
  • 기여도
    UI · UX 100%
  • 사용 프로그램
“안심하고 먹을 수 있는 건강한 과일 간식, 어디 없을까?”
과일은 건강한 식품이지만
직장이나 외출 중 간편하게 즐기기에는 손질과 보관의 번거로움, 가격 부담 등의 이유로 일상 간식으로 선택되기 쉽지 않습니다.
또한 아이에게 줄 간식을 고를 때 건강과 맛을 동시에 만족시키는 선택지는 많지 않습니다.
헵시바F&B는 이러한 고민에서 출발해
좋은 재료로 정직하게 만든 과일 간식을 통해 누구나 안심하고 즐길 수 있는 건강한 간식을 제안합니다.

Current Issues
현황 분석과 문제점을 아보기 위해서 데스크 리서치를 행하였습니다.
  • 브랜드의 핵심 가치와 제품 특징이 웹사이트에서 직관적으로 전달되지 않고 있어요
    Solution 1
    Brand Identity 강화
    메인 비주얼에서 브랜드 메시지와 제품을 함께 강조하여 사용자가 건강한 과일 간식 브랜드임을 빠르게 인지할 수 있도록 개선했어요
  • 기존 웹사이트의 디자인이 올드한 분위기로 구성되어 있어 브랜드의 신뢰감과 트렌디한 이미지 전달이 부족했어요
    Solution 2
    Modern UI Renewal
    최신 UI 트렌드를 반영한
    레이아웃과 비주얼 요소를 적용하여
    건강하고 감각적인 브랜드 이미지를 강화했어요
  • 메인 화면에서 제품이 충분히 강조되지 않아 사용자가 어떤 브랜드인지 빠르게 이해하기 어려웠어요
    Solution 3
    Product Visibility 강화
    대표 제품을 메인 콘텐츠 전면에 배치하여
    브랜드와 제품 특징을 직관적으로
    전달할 수 있도록 개선했어요
